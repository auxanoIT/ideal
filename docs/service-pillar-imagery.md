## Delivery and reuse

Generated images are delivered as 1200-pixel-wide WebP files. The Smart Hands card reuses the existing generated infrastructure-support image as an optimized WebP. Network, hardware, audit and lifecycle cards reuse existing descriptive service-detail assets. Each card has a specific alt description and a crawlable link to its existing services overview anchor.
